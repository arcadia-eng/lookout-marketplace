# Security Policy

Report through the Security tab, Report a vulnerability. Do not open a public issue.

Scope is the feed gate, plugins/lookout/ and servers/lookout-mcp/. The supported set is the latest v* tag for the plugin and the latest lookout-mcp-v* tag for the server.

The server binds 127.0.0.1, and LOOKOUT_MCP_TOKEN is an operator credential, so do not paste it.
